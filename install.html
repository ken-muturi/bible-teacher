Install Bible Teacher

On your phone, tablet, or in a browser — about two minutes, no downloads.
This sets up all the Bible Teacher tools at once inside a Claude Project. You do it once; then in that project you just type things like passage-study John 3 and Claude does the rest.
Tap the button, then follow the 3 steps below.
  1. Copy — tap the green button above. done in one tap
  2. Make a Project — open the Claude app → menu → Projects → New Project. Name it "Bible Teacher".
  3. Paste it in — open the project, go to Project knowledge (or "Add content" → "Add text"), paste, and save. That's the whole install.
Check it worked: start a new chat inside the Bible Teacher project and type passage-study John 3:16. You should get a small formatted study panel (plus a short summary). The first time, Claude may ask a few questions about your Bible translation and tradition — answer once and it remembers.
Using Claude Code instead? (the developer terminal / the "Code" tab) — you don't need this page. Just run:
/plugin marketplace add ken-muturi/bible-teacher
/plugin install bible-teacher@bible-teacher
Button didn't work? Some phone browsers block copying. Tap this link, then Select All → Copy the text by hand — or copy from the box below.
